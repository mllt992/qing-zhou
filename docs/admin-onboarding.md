# 管理员部署检查清单

新环境的管理员控制台及管理概览会显示可关闭的部署检查清单。它只提供提示和现有配置页入口，不阻断用户、修改计费/节点配置或自动安装软件。关键项都完成时自动隐藏；「系统设置 → 重新打开部署检查清单」可随时重新打开。关闭状态只保存在当前浏览器、当前管理员账户下。

检查项：
- HTTPS 访问地址已配置（不等于主动验证公网连通性或证书）
- 至少一台启用节点近期完成 sing-box 检测，包含使用本机作为节点的部署
- 启用节点有 `with_v2ray_api`；明确缺失显示红字，失联/过期结果标记待检测，不能把旧成功当作当前健康
- 启用节点上存在已启用的入站
- 已上架的套餐绑定到含启用节点的分组，避免空分组造成空订阅
- 可选：注册码、公告、SMTP，这些不影响清单完成

页面每30秒读回持久状态，切走页面会取消未完成请求并清理定时器。读取失败时可重试，普通功能继续可用。清单的读取不会发起 SSH 或重装；前往服务器页可使用既有检测/重装流程，重装仍需原有明确确认。

服务器、套餐和入站空列表也提供下一步说明与对应创建按钮。已完整配置的环境不会反复展示清单。
