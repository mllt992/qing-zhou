# 管理端权限与用量报表

## 节点管理

节点卡片和分组卡片的「可用用户」是当前有权限的去重用户数，不是在线人数。禁用节点、缺失/禁用入站、已失效的固定出口链路不计入可用节点；封禁用户不计入。开启邮箱验证门槛时，未验证且未获得付费套餐准入豁免的账号也不计入；管理员及既有准入豁免保持原规则。

点击人数查看分页名单、有效套餐/额度、累计已用、剩余额度与到期时间，包含从未消耗流量的用户。同一用户的多个有效额度不会重复增加人数。排队套餐不授予权限；额度耗尽后的公共池、赠送额度和免费组规则复用实际订阅的额度解析器。

弹窗中的额度累计用量属于该额度整体，不能当作这个节点上的流量。当前权限变化不会修改历史用量。

## 用量统计

- 机器：选择「面板本机」（来源 ID 0）或远程机器与近 7 / 14 / 30 天，查看实际记录的用户上传、下载、合计、排名、占比与每日趋势；另一个页签展示当前入口节点可用用户，包含零用量用户。
- 套餐：选择套餐查看当前有效用户；下方原有套餐筛选、用户排名、按套餐明细及 CSV 仍可查看历史实际消耗。
- 用户：原有用户筛选、累计/时间区间、排名和图表继续使用相同口径。

机器数据来自 sing-box 的机器×用户采样，只有约 35 天保留期。首/末条记录只是本次查询的观测边界，并不证明期间采集连续。没有记录不代表实际使用为零。机器用户流量不是物理网卡流量，也不是服务商结算数；转发、系统服务和计费方向可能造成差异。

历史机器采样没有套餐维度，无法反推出某机器的历史套餐消耗。不能把用户现在的套餐关联到过去的机器用量。本次不添加猜测式回填、不迁移或修改生产数据。

权限名单、计数与机器报表接口均只对管理员开放，不返回代理密码或身份密钥。计数使用专用汇总路径，详情按选定维度裁剪；每个请求使用一致性数据库快照。

## 管理布局

上游管理在注册码之后。部署检查清单放在系统设置的独立入口，完成或以前关闭的清单仍可查看。机器健康固定显示在监控管理；「首页显示机器健康」默认关闭，打开后仅管理员在首页及用户控制台可见。普通用户和访客不能据此读取管理端健康数据。

## 本地性能核验

测试数据为 3,000 用户、6,000 套餐额度、200 节点、20 分组，单次计数约 28 ms / 7.3 MB 分配，单节点详情约 17 ms / 4.6 MB（共享开发机测量，不是生产容量承诺）。可运行 `go test ./internal/store -run '^$' -bench BenchmarkAudience3000Users200Nodes -benchmem` 重测。
