# 业务提醒邮件

系统设置 → 邮件服务新增「业务提醒邮件」总开关，默认关闭。开启且 SMTP 可用时，每五分钟检查套餐即将到期/刚到期及流量不足/用尽，提醒阈值复用现有 `notify_expiry_days`（默认 3 天）与 `notify_traffic_percent`（默认 20%）。自动提醒只发送给正常状态、邮箱已验证的账户。

用户可在账户设置关闭业务提醒邮件。总开关及用户偏好也覆盖管理员的手动通知邮件；待发送的手动邮件在投递前重新检查，关闭后记录「已跳过」及原因，不继续发送。关闭邮件不影响 Telegram 自己的通知偏好。升级后若要继续使用手动邮件通知，管理员需明确开启此总开关。

邮箱验证、找回密码及账号安全邮件属于系统邮件，不经过上述开关。SMTP 测试邮件也仅由管理员明确发起。

同一事件按用户、事件、对象和渠道去重，旧 Telegram 记录原样保留。连接失败或 SMTP 明确拒收可在下一轮重试；DATA 已获接受后 QUIT 失败不算投递失败，DATA 回执丢失时保留去重记录并记录不确定状态，避免自动重复发信；流量恢复后清除该渠道的不足/耗尽记录，下一次再次不足才重新通知。用户关闭提醒期间仍维护恢复状态，避免重新开启后遗留旧状态。无 SMTP、总开关关闭、邮箱未验证或用户关闭时不生成新通知、不对外发信。

邮件沿用手动通知的 `{{plan}}`、`{{expiry}}`、`{{remaining}}` 等变量渲染与 HTML 转义。这里不包含支付、自动续费或任何新的外部服务配置。
