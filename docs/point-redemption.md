# 积分兑换码

管理员在「积分兑换码」页面生成一次性积分码，设置面额（1–10 亿积分）、张数（1–100）、有效期（1–3650 天）及批次备注。每张码只能兑换一次，不包含在线支付、售卡、签到或邀请功能。

完整码只在生成成功后显示一次，可复制全部；数据库只保存 SHA-256 哈希和码尾标识。每张码含 128 位安全随机数，与顺序 ID 无关。请立即保存并通过合适渠道交给用户；若未保存，停用该批未使用的码后重新生成，不支持还原原码。列表支持状态筛选、分页和批量停用，并显示兑换人、兑换时间，用户删除后仍保留用户名审计快照。

用户可在「积分明细」或商城的「使用兑换码」入口兑换。接口在同一 IMMEDIATE 事务中完成一次性核销、余额增加和 `redeem` 流水写入；任何一步失败都会回滚。并发提交同一码只会到账一次。浏览器不会因网络错误自动重发兑换写请求；若响应丢失，请先查看余额和积分明细。

防滥用：用户每分钟最多 10 次请求，来源 IP 每 10 分钟最多 100 次；连续 5 次无效兑换后，数据库持久锁定该账户兑换 15 分钟，重启不能绕过。成功兑换会清除连续失败记录。过期、已停用、已使用和不存在分别给出清楚提示。

兑换入口不涉及付款。没有兑换码或兑换不可用时，请联系管理员。
