# v0.2.80 — 认证中心接入、登录排版与网络稳定性

- 登录、注册和找回密码弹窗统一上方标签、等宽输入框和字段间距；适配窄屏，修复带登录参数进入首页时弹窗未打开的问题。
- 管理后台新增“OAuth2 / OIDC”配置区，可填写认证中心 Issuer、Client ID、Client Secret、回调地址，测试 discovery、启用登录及控制首次自动开户。采用授权码 + PKCE S256、RS256 ID Token 校验及一次性浏览器状态；已有账号在账户设置中以当前密码确认绑定，不按邮箱自动合并。详见 [接入说明](../oauth2.md)。
- 新增 OAuth 身份绑定、一次性认证状态两张表，自动迁移。客户端密钥和 PKCE verifier 使用现有密钥体系加密存储。OAuth 登录使用 HttpOnly Secure Cookie，不把轻舟令牌放入跳转 URL。
- 订阅源仅在 HTTP 200、完整读取、不超过 8 MiB 且包含有效节点时替换结果。HTTP 错误、截断、超限、HTML、空或无效订阅只更新 `last_error`，保留最后成功节点、分组、抓取时间和计数。成功替换与分组绑定使用同一事务；定时抓取读取最新分组，删除中的订阅源不会留下孤立节点。
- 订阅抓取复用 API 生命周期内的 HTTP 连接池，限制连接数量及 DNS/拨号、TLS、响应头、空闲连接时间；继续在拨号时校验全部 DNS 结果并直连已校验 IP，保持 SSRF、DNS rebinding 和 TLS 防护。退出时取消并等待订阅同步、关闭空闲连接。
- 请求处理超时保持 30 秒，HTTP 写入超时调整为 45 秒，为超时响应预留 15 秒。节点 ping 每请求最多 32 个 worker、API 实例最多 64 路拨号，等待和拨号均响应请求取消。
- 配置下发、能力探测、远程流量采集与诊断共用 8 路 SSH 上限，在启动任务前取得额度；采集取消会停止排队与在途请求。远程统计及 Telegram 响应补充状态码与超限检查。
- 前端 API 默认超时 45 秒，覆盖 JSON/附件响应体读取；所有封装新增可选 `signal` 与 `timeoutMs`（0 可禁用超时）。读取损坏的成功响应会报错，避免显示为成功的空列表。不会自动重试写操作。
- probe 上报失败后对下一次新采样使用有抖动的指数退避，成功后恢复面板指定周期；不重放旧 POST、不跟随重定向，避免重复指标或计量。保持旧面板不返回周期字段时的兼容行为。
- CI 与发布构建增加前端网络及认证回归测试，并执行包含类型检查的生产构建。

## 验证与运行说明

验证命令：`go test ./...`、`go test -race ./...`、`go vet ./...`、前端 `npm test`、`npm run typecheck`、`npm run build`、`git diff --check`。认证回归覆盖签名、issuer/audience/nonce/过期/at_hash、userinfo subject、浏览器绑定、回调重放、注册限制、邮箱冲突、停用账号、管理员实时权限、密钥屏蔽和数据库回滚。浏览器已检查桌面与 375px 移动端布局。网络回归覆盖数据保留、事务回滚、抓取期间分组编辑/删除、SSRF/重定向/TLS、连接复用及空闲回收、并发上限、取消、超时响应和禁止写入重放。

chi 超时中间件是协作式取消，handler 需响应 context；本次修改的抓取与 ping 会在取消后返回，由中间件发出 504。大型节点列表可能因 30 秒总预算而超时。SSH 下发继续使用异步任务，每台节点的 90 秒预算在取得并发额度后开始，节点多时总下发耗时会增加。probe 需直接配置最终面板 URL，不能依赖 HTTP→HTTPS 重定向。退避最长为 5 分钟或原采样周期（取较大值），故障期间不堆积历史 POST。

版本沿用发布标签注入，不修改前端独立的 package 版本。sing-box 仍固定 v1.14.0（发版前已核对上游最新稳定版）。

认证中心与轻舟回调地址须为公开可访问的 HTTPS 地址，认证端点与 Issuer 同源。首次开户默认关闭；启用后仍需本站开放注册，且遵守邮箱验证规则。未对实际认证中心创建应用或填入生产密钥；接入管理员需要登记回调地址并完成一次实际授权登录。
