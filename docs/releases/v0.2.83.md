# v0.2.83 — 首页卡片显示控制

## 功能增强

### 面板本机 · 三态显示
- 监控管理里，面板本机从「公开开关」改为 **公开显示 / 仅管理员 / 不显示**。
- 默认 **仅管理员**：登录后的首页能看到本机卡片，未登录公开页不显示。
- 选 **不显示** 后，管理员首页也不再注入本机卡片。
- 选 **公开显示** 后，未登录首页也会出现本机。

### 上游余额 · 独立开关
- 「上游余额」不再绑在面板本机后面，成为独立首页卡片。
- 开关放在 **上游管理** 页顶部，只对管理员首页生效，公开页始终不显示。
- 未配置上游时默认关闭；配置 OCI 或 Cloudflare 任一后默认打开；手动关闭后记住该选择。

## 技术改进
- 本机三态写入 `monitor_local_home_visibility`，并同步旧的 `monitor_local_public`，旧库升级后按原公开布尔回退。
- 隐藏上游余额时不再轮询官方用量接口。
- 新增本机三态与首页卡片门控的前后端测试。

## 验证与运行说明
- 验证命令：`go test ./internal/api -run 'Local|PublicPage'`、前端 `npm test`。
- 升级无需手工迁移；刷新监控管理页即可看到本机下拉。
