# v0.2.80 网络改动复审

范围：以 v0.2.79（1818b2c）为基线，初始代码审查后实施修复，再重新检查最终差异、生产调用链与回归测试。网络部分未更换协议或计量模型；追加 OAuth2/OIDC 接入引入两张独立的新表，保留本地账号登录。

## 复审结果

没有剩余 P0/P1 问题。复审发现并已修复以下边界：

1. 失败抓取不能提前持久化新分组；改为节点与分组同一事务提交。定时同步在事务中读取最新绑定，避免覆盖抓取期间的编辑；已删除的源不能产生孤立节点。
2. 订阅头可能错误标为 `text/html`；根据真实响应体拒绝 HTML，保留有效纯文本/base64 的兼容性。
3. HTTP Transport 可以为复用继续执行拨号；给 DNS 查询和全部候选 IP 共同设置 10 秒预算，防止只限制 TCP 连接阶段。
4. 单独限制两类 SSH 操作会在同时执行时翻倍；采用 Controller 共用的 8 路额度，并在 goroutine 启动前取得额度。能力探测和诊断也受同一限制。采集的 DNS/能力探测继承调用 context，取消不写入负缓存。
5. probe 的 307/308 重定向可能重放写入；禁止跟随重定向。失败后只安排新样本，保留计量入口和累计网络计数器语义。
6. 前端超时必须覆盖响应体，并在异常路径清理计时器和 AbortSignal 监听器；损坏 JSON 不再被解释为成功的空列表。

## 检查依据

- 数据保留：失败路径在解析、读取及大小检查后均仅写 last_error；成功路径为事务。测试比较完整节点（含 ID、分组）及订阅元数据，并注入中途数据库失败验证回滚。
- 并发与取消：ping 为固定 worker，每个槽位在成功或失败后释放；共享槽位等待可取消。SSH 在进入 goroutine 之前限流，统计客户端在释放额度之前关闭隧道。取消测试等待工作退出并验证活跃数归零。
- 连接复用：API 持有单个安全客户端；完整成功响应读到 EOF 并关闭 body。错误、超限响应直接关闭，避免为复用而继续读取恶意无界响应。空闲连接定时清理，关闭时显式释放。
- SSRF 与 TLS：一次解析、检查全部 DNS 答案、只拨打已验证 IP；不使用环境代理。重定向私网地址、IPv4/IPv6 私网、空 DNS 答案、证书失败、公开 IP 回退都有测试。
- 超时：30 秒处理预算和 45 秒服务端写预算分离。真实 socket 测试验证协作式 context 超时产生可接收的 504；保持 gzip 顺序，不引入可能破坏流式下载/ResponseWriter 接口的全局响应缓冲。
- 兼容性：API 新选项为可选参数；原有信封、raw JSON、列表行为保持。旧面板未返回采集周期时继续采用原周期；没有新增写请求重试或旧样本重放。
- 同类问题：修复远程统计及 Telegram 对状态码/超限的漏检。检查更新器下载路径已有状态、读取错误、大小与校验/签名保护；出口 IP 探测已有状态与解析校验、短生命周期客户端关闭。

## 验证门槛

发布前必须在最终代码上通过 Go 全量测试、全量竞态检测、go vet、前端网络测试、类型检查、生产构建及 git diff --check，并核对 GitHub CI。标签沿用附注普通标签惯例；二进制签名继续由已有发布密钥和工作流生成。发布完成状态以 GitHub 工作流成功及实际上传资产为准。

## 已知运行边界

chi 超时为协作式；不会强制中断不理会 context 的任意旧 handler。SSH 单节点下发仍为 90 秒预算，8 路批处理使大规模下发总耗时增加，但 API 沿用异步调度。probe 重定向现在会报错，需配置最终 URL。发布包大小警告和已有依赖审计结果没有在此变更中做无关依赖升级。

## 追加任务复审：认证中心与登录弹窗

采用成熟 go-oidc/oauth2 库验证签名、issuer、audience、expiry；额外核对 nonce、at_hash 和 userinfo subject。授权请求使用 S256、10 分钟一次性数据库状态与 __Host- 浏览器 Cookie，成功/失败回调不携带轻舟 JWT 或上游错误文本。配置变更会使尚未消费的旧流程失效。所有上游请求复用安全拨号器、限制同源 HTTPS、拒绝重定向、限制 1 MiB 响应及 8 路并发。

身份只由 issuer + subject 匹配，不由用户名/邮箱匹配；已有邮箱冲突要求先登录原账号绑定，绑定同时校验当前密码和原会话。自动开户仅在开放注册且允许自动开户时执行，遵守邮箱验证要求，角色固定 user。新账号及身份在一个事务中创建，代理凭据固定，配置下发异步；持久化 provisioned 标记避免登录重复发放首次额度。OAuth 管理接口拒绝 API token，并核对管理员当前角色和状态。

新增表自动迁移，删除账号级联删除绑定。OAuth config 使用现有加密设置体系；PKCE verifier 加密，state/browser binding 只保存摘要。密钥 *** 保留语义、非法配置不写库、同源 discovery 和事务中途失败均有回归。

前端使用 Cookie 恢复 OAuth 会话，回调先清理旧 bearer，401 清理本地状态不会循环发送注销请求。桌面及 375px 注册表单实际浏览器测量等宽；登录/注册/找回密码的标签、输入框和间距统一。

验证使用独立 TLS OIDC 测试服务，按“认证中心”项目公开接口构造 RS256/S256/nonce/basic-auth/userinfo 合同。未连接或更改实际认证中心数据库；生产应用配置及真实授权登录仍需管理员完成。
